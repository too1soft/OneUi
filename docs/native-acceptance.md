# 原生验收清单

每个组合独立保存报告，字段至少为：产品、版本、profile、程序架构、原生系统架构、OS/SP/补丁清单、制品哈希、build ID、时间、测试版本、每项结果和附件哈希。
状态限定：passed / failed / not-run；空项不是通过。记录密码或令牌时必须脱敏；测试凭据不放进制品或报告。

## 环境

- 原版 Win7 SP1 x86 和 x64，不预装汇总补丁、VC 运行库或新 PowerShell。
- Win8、Win8.1 各位数；Win10 x86/x64、Win11 x64。
- 普通用户 / 管理员、中文路径、离线、真实网络、CPU 基线。
- 系统识别失败、Vista、Win7 无 SP1、ARM64 应阻断；不崩溃或猜测安装。

## GUI

- 真实登录、协议未勾选、二维码过期、网络失败；不要自动操作用户认证。
- 中文字体、输入法、菜单、弹层、键盘焦点、100%/125%/150%/200%、跨屏。
- 日志、托盘关闭 / 恢复 100 次、退出清理、休眠恢复、长期运行。
- 共享启动 / 停止、密码、特殊文件名、Range/HEAD、大文件、目录越界保护。

## 连接与无界面程序

- HTTP / HTTPS / TCP 等已支持协议、真实来源传递、本地服务错误、断网重连、节点升级后重连。
- 安装服务、开机启动、停止、日志、人工升级、文件占用、失败还原及数据保留。
- 从 CLI 与 GUI 分别验证，不因它们共用代码而省略其中一个入口。

## OneUpdate / 信任

- 在线、离线、便携安装、取消、重复请求、断网、磁盘不足、文件占用、损坏包。
- 错 profile、架构、最低系统、未验收系统、旧协议、签名篡改全部不可激活。
- 底座维护进程升级、精确健康确认、失败回滚、重新启动后的事务恢复、卸载。
- 原版 SP1 真实公网 HTTPS 与发布签名链；本地生成的可信 TLS 测试证书不代表公网根证书链验证通过。
- 不降低签名、TLS 校验或文件保护完成验收。

## 本轮原生证据的边界

当前 VirtualBox 为原版 6.1.7601.17514 x86、无额外补丁。2026-09-09 为公网信任探针启用 NAT 出站网络，没有端口转发；未安装额外根证书、运行库或汇总补丁。
Go 本地 TLS / 文件 / 目录边界 / 线程 / 进程冒烟、cdecl 循环、Agent/安装器命令行启动仅是基础检查。
OneUI 既有 27/35 项原生检查仍有效，但其 QA 导出帧不是完整 WYC 实机交互截图。
API 域名的原生 TLS 握手通过；登录域名握手出现超时，不能把一次 API 握手通过外推为全部公网信任通过。
Win7 x64 按本次用户要求延期原生测试，保留精确构建的例外记录；Win8/8.1、GPU/输入法/真实 DPI、完整公网信任和业务更新闭环均不得据此销项。
