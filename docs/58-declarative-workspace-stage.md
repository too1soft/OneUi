# 声明式模板与工作区：阶段完成说明

日期：2026-09-28。状态：**C++／`.one` 声明式开发第一阶段完成，可作为继续开发应用的基线；仍为 0.1 开发版。**

## 完成到什么程度

- C++ Compose 和 `.one` 共用 ViewModel、原生组件与保留控件树，包含属性绑定、双向输入、事件、条件、稳定 key、模板组件与插槽。
- `oneui-viewc` 在构建时生成 C++，检查组件／属性／事件／表达式和结构，错误可定位回模板；不引入 JavaScript 或 WebView。
- 既有 CSS 解析器提供严格诊断、scoped 和开发热更新，支持错误回滚、删除规则与输入状态保留。模板结构变化仍需重建。
- 默认表单、页面组合、主题和密度可直接复用；新增 Workspace／DockPanel 等语义区域，使终端、文件、监控工作区不必手算子控件坐标。
- NativeHost 可承载 Rust 所有者提供的原生控件；示例接入稳定 ID 标签、分隔区、分屏、虚拟表格和监控图表。
- SDK 内置诊断、动效连续性修正、阴影缓存与原生控件修复一并纳入本次阶段提交。文档、README、原生截图和验证数据一起交付。

使用入口：[十分钟上手与示例](../README.md)、[声明式接口](35-declarative-authoring-v1.md)、[工作区快速布局](57-workspace-layout-components.md)。

## 明确保留的后续工作

真实 OS 中文 IME 候选窗、跨显示器 100%／125%／150% DPI 交互仍需专门验收；不能用合成 composition 或栅格缩放测试代替。完整 Vue 语法、JavaScript、模板直接生成 Rust 以及全面浏览器 CSS 不属于这一版承诺。

终端示例使用本地模拟连接、命令、文件和监控；真实 SSH／PTY／SFTP、完整拖拽停靠、浮动窗口与布局持久化不在本阶段交付中。现有底层能力不等于这些功能已统一接入 `.one`。

此次没有重新测量代码入口和模板入口的 CPU／内存差异；历史实测见[原声明式阶段报告](40-declarative-stage-validation.md)，不能把功能测试解释为新的性能提升百分比。
