# 版本、渠道与 SDK 契约

官网与自动下载命令读取同一份 releases.json，文件内容校验后才开始服务。下载文件与清单放在 Go 程序旁。

## 当前版本

2026-10-13 新增 `0.1.0-preview.2`（ABI 44），目前提供 Windows modern x86_64 的动态/静态 SDK 与单独 DLL。其他目标继续使用对应的 preview.1 包。实际发布及维护者一键流程见 [官网 SDK 自动构建与发布](sdk-publish-automation.md)。头文件、语言绑定和库须按版本一起更新。

0.1.0-preview.1 是 ABI 43 的预览快照。Windows、macOS、Linux 的产物均来自实际构建，使用匹配头文件和依赖清单。源码包含尚未提交的工程变更，因此来源清单保留 sourceDirty=true 和源文件哈希，不把 HEAD 提交号当作全部源代码身份。

完整原生验收和正式发布签名尚未完成，因此当前没有稳定版。下载中心会显示真实空态；已构建不等于已在所有目标系统完成验收。

## 发布渠道

| 渠道 | 用途 |
|---|---|
| stable / 稳定版 | 完成版本规定的发布门槛，适合经业务验证后采用 |
| preview / 预览版 | 可下载、可集成验证；仍需关注明确列出的验收缺口 |
| experimental / 实验版 | 尝试新能力，兼容性和保留周期由版本说明给出 |

渠道用于发现版本，项目锁定具体版本。不会在每次业务构建时自动追踪 latest。

## 内容不可覆盖

同一个版本和目标的文件发布后不能替换。代码或依赖改变时发布新版本，并保留旧版本及对应文档。每个包列出系统、架构、工具链、ABI、链接方式、来源与文件 SHA256。

新增版本时，先验证所有包和消费者，再更新清单并重启服务。程序会拒绝缺失、大小不匹配或哈希错误的下载文件。已有文件被替换时，下载会失败而不是返回未经启动校验的新内容。

## SDK 目录契约

| 路径 | 内容 |
|---|---|
| sdk-manifest.json | 完整文件清单、哈希、ABI、来源、系统和静态链接信息 |
| include/oneui | 与库匹配的公开头文件 |
| bin / lib | 原生运行库、导入库或静态库 |
| cmake | 可移动的 OneUIConfig 与目标定义 |
| bindings/rust | 配套 oneui / oneui-sys 源码包装，不重新编译 C++ SDK |
| examples | 可编译 C/C++ 最小消费者 |
| licenses | 实际依赖许可和版权说明 |

静态 SDK 的第三方库不应自行删减；使用 CMake 入口让依赖关系由 SDK 维护。

## 兼容与升级

ABI 版本与产品版本分开。跨语言调用优先通过 UTF-8 C ABI；C++ 调用还必须满足架构、工具链和运行库兼容要求。Rust 包与 SDK 头文件、库一起升级，不混用不同版本包装。

升级流程：修改锁定版本、下载校验、编译业务程序、执行自身功能与安装更新回归、再发布业务软件。框架的集中测试不能替代业务应用验收。

## 文档快照

本 Go 程序内嵌 0.1.0-preview.1 的文档快照与仓库工程资料。工程记录保留其阶段语境；当前产物状态以下载页和平台矩阵为准。未来发布需要同时带入新增版本文档，不能只修改版本选择器。
