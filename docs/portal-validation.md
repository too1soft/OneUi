# 0.1.0-preview.1 交付验证

本页记录首批预编译 SDK 与 Go 官网的实际验证，不代表全部平台已完成稳定版认证。

## SDK 消费者

每个压缩包都实际解压，通过包内 CMake 入口编译 C、C++ 示例；Rust 使用压缩包内的安全绑定，校验 SDK 清单后编译并创建原生窗口。所有测试只链接预编译库，不构建 OneUI 或 Skia。

| 下载目标 | C / C++ 动态、静态 | Rust 动态、静态 | 实际运行环境 |
|---|---|---|---|
| Windows legacy x86 | 通过 | 通过 | Windows 10 x64 主机，x86 进程 |
| Windows legacy x86_64 | 通过 | 通过 | Windows 10 x64 主机 |
| Windows modern x86 | 通过 | 通过 | Windows 10 x64 主机，x86 进程 |
| Windows modern x86_64 | 通过 | 通过 | Windows 10 x64 主机 |
| macOS native arm64 | 通过 | 通过 | 原生 macOS 15.5 arm64 |
| Linux Ubuntu 24.04 x86_64 | 通过 | 通过 | WSL Ubuntu 24.04、Xvfb / X11 |

共 24 次 C/C++ 运行、12 次 Rust 运行通过。Windows C/C++ legacy 使用 MSVC 19.44，modern 使用 MSVC 19.50；Rust Windows 验证使用当前 MSVC 目标。本轮没有把 Rust 程序放到 Win7 上运行，旧系统应用还需要选择兼容的 Rust 工具链、目标和依赖。

## 官网与下载（2026-10-08 首次交付）

- Go 自动测试覆盖静态页面、未知地址、下载白名单、路径穿越、符号链接、文件变化、损坏文件、HEAD、Range、ETag、HTTPS 与重定向限制。
- 共享缓存验证首次下载、新项目复用、项目版本锁、离线使用与文件损坏拒绝。项目锁写入加互斥，避免并行会话覆盖其他目标。
- Windows 服务实际启动；Linux x64 服务从其他工作目录启动，完成首页、下载页、文档直达、清单、健康检查和 Range 下载。
- 浏览器验证手机菜单、渠道空态、系统/架构/链接筛选、文档搜索、代码复制与主题切换；全部 12 个下载接口与声明大小一致。
- 发布清单新增版本保留历史记录，默认拒绝覆盖已有版本。正式稳定版本不允许使用候选替换参数覆盖。

## 验收边界

这批包保留了实际脏工作树来源和 ABI 43。当前只发布预览快照，没有正式代码签名或服务器上线声明。用户已确定官网域名为 oneui.too1.net，实际部署待验证。

Linux 真实桌面的通知冷启动、系统拖放、输入法与多屏 DPI 仍待原生验收。Mac 当前下载包没有 Developer ID 签名或公证。Win7 兼容库的旧系统测试记录与本轮下载包消费者检查是不同证据，不能合并成完整产品认证。更详细的系统依赖见[平台矩阵](sdk-platforms.md)。

原始机器报告保存在仓库固定路径 `out/native-release-review/portal-*`；交付目录的 `verification.json` 包含本轮消费者、浏览器和 HTTP 摘要，`SHA256SUMS` 用于复核交付文件。

## 2026-10-09 DLL 下载优化

本次从原 Windows 动态 SDK 提取 4 个独立 DLL，并保留原有 12 个 SDK ZIP。没有重新编译 OneUI 或底层依赖；原 SDK 消费者证据仍对应原包。

新增自动测试覆盖 DLL 的 GET、HEAD、Range、ETag、大小及内容一致性，拒绝不合法路径、错误平台/链接组合、重复名字、损坏及缺失 DLL。发布构建还通过进程内 HTTP handler 检查实际嵌入页面和全部交付文件；这些检查不代替浏览器交互验收。

本轮浏览器工具被 URL 安全策略阻止访问本地预览，没有绕过。新的 Windows 系统版本筛选和 SDK/DLL 双下载按钮仍需在浏览器中复核；已有旧版截图只用于设计参考。本次服务端测试和构建结果以交付的 verification.json 为准。
