# Bundled UI font

`NotoSansSC-wght.ttf` is the unmodified Noto Sans SC variable font from the
Google Fonts repository. It is registered from process memory by OneUI and is
not installed into the operating system.

- Family alias: `Noto Sans SC`
- Weights: 100–900
- Upstream commit: `2894aab31764f10f29c421bdfd2340d3b382d384`
- Font SHA-256: `A3041811A78C361B1DE50F953C805E0244951C21C5BD412F7232EF0D899AF0DA`
- License: SIL Open Font License 1.1 (`OFL.txt` in this directory)
- Source: <https://github.com/google/fonts/tree/main/ofl/notosanssc>

Keep the font binary unmodified so the upstream Reserved Font Name terms
remain straightforward. Distributions that enable the `bundled-fonts` feature
must retain the included OFL license text.
