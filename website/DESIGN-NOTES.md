# OneUI 官网设计映射

## Overview

本文件记录 [PORTAL.md](PORTAL.md) 所定义的官网扩展在 `website/app` 中的实际实现，模式为 Read / Operate。首页提供 SDK 下载和接入文档入口，下载中心用于选择真实产物，文档页用于查找并阅读版本化内容。

根目录 [DESIGN.md](../DESIGN.md) 的绿色浅深主题和清晰内容层级继续作为品牌依据；它的数值与组件描述以原生 SDK 为适用范围。官网实际颜色、字号、间距与响应式行为以 [main.css](app/assets/css/main.css) 为准。本文件不新增 token，不将官网 CSS 数值改写为 SDK 默认值，也不改变根设计文件或其 sidecar。

本轮文档检查读取当前源码及已有真实截图：[桌面首页](../.impeccable/review/desktop.png)、[手机下载页](../.impeccable/review/mobile.png)、[桌面接入文档](../.impeccable/review/docs-desktop.png)。截图支持相应页面与视口的视觉核对，不能代替所有主题、交互、平台或 SDK 的完整验收。功能验证及交付边界见 [portal-validation.md](../docs/portal-validation.md)。

## Colors

官网使用 `--canvas`、`--surface`、`--ink`、`--muted`、`--line`、`--soft`、`--accent` 与 `--accent-ink` 分配背景、正文、辅助信息、分隔线和交互强调；代码区域使用 `--code` 与 `--code-ink`。`:root` 与 `.dark` 定义两套对应角色。

绿色强调用于主操作、选中导航、链接与聚焦轮廓。预览渠道、平台限制、验证范围和签名状态均同时提供文字。官网未采用原生工作区可选的蓝色主题。

## Typography

正文沿用系统中文字体，当前字体栈为 Segoe UI、PingFang SC、Microsoft YaHei 与 sans-serif；没有下载字体依赖。正文基准为（15px / 1.7），文档正文为（14px / 1.95），代码保持等宽字体。首页标题、页面标题和文档标题分别由其所在区域的 CSS 控制，不能套用原生 SDK 的固定标题尺寸。

辅助信息使用 muted 角色，操作与内容标题保持较强层级。文档搜索占位文字显式使用 `--muted` 且 `opacity: 1`，避免继承框架的半透明占位样式。原 finish reviewer 的唯一问题 F1 已按该修复限定复核为 resolved / ship；该结论不是全站无障碍认证。

## Layout

整体内容最大宽度为（1200px），桌面两侧各留（32px），手机两侧各留（18px）。顶部导航保持固定在可视区域顶部。首页以简介与接入步骤并列呈现，正文使用分隔线和列表组织入口。

文档桌面布局依次为分类导航、可伸缩正文和页内目录；宽度不大于（1100px）时收起右侧页内目录。宽度不大于（760px）时使用单列正文，主导航改用菜单，文档目录由按钮展开；两类导航均在切换路由后收起。

下载筛选在桌面横向排列，在手机上按两列与整行组合呈现；下载条目转为单列，下载按钮占满条目宽度。长代码与文档表格使用局部横向滚动，正文允许长字符串换行。

2026-10-09 下载优化延续同一视觉语言：默认 Windows 现代 x64 动态版，增加系统兼容版本筛选；首次接入突出完整 SDK，单独 DLL 为次要操作，标明匹配版本及重命名要求。版本说明默认折叠，保留包旁的验收与签名状态。筛选值随可用架构同步，提供查看全部目标入口。当前轮浏览器访问被 URL 安全策略阻止，新的响应式与交互效果尚无本轮真实截图，不能沿用上轮 ship 结论。

## Elevation & Depth

当前官网通过背景色、柔和填充与细分隔线建立层级，没有阴影卡片体系。代码区域以深色底分离。焦点由绿色轮廓表达；按钮使用短暂的背景过渡，减少动态效果偏好关闭过渡。

## Shapes

组件使用已有 CSS 中的轻微圆角：主按钮（7px）、搜索与选择控件（6px），代码区域与说明容器使用各自的局部圆角。下载条目和文档分类以分隔线组织，不将它们包成重复的大卡片。这些是官网的实现映射，未新增共享圆角尺度。

## Components

| 实现 | 当前职责与可见状态 |
| --- | --- |
| [SiteHeader.vue](app/components/SiteHeader.vue) | 首页、下载、文档、组件参考入口；主题切换；跳到正文；移动菜单提供展开状态和受控区域。 |
| [DocsSidebar.vue](app/components/DocsSidebar.vue) | 分类、当前文档标识、本地搜索、匹配数量及无结果说明；手机目录展开按钮。 |
| [downloads.vue](app/pages/downloads.vue) | 渠道、历史版本、操作系统、架构与链接方式筛选；清单读取中、错误重试、空渠道和无匹配产物状态。 |
| [ArtifactDownload.vue](app/components/ArtifactDownload.vue) | 清单中的实际下载链接、大小、最低系统、工具链、验证及签名文字；展开后提供 SHA256、系统依赖和自动接入命令。 |
| [CopyCode.vue](app/components/CopyCode.vue) | 保留可选择代码；复制成功与失败均用状态文字反馈。 |
| [文档正文页](app/pages/docs/[slug].vue) | 版本说明、正文与锚点、代码复制、历史工程记录提示、返回目录与下载入口。 |

## Do's and Don'ts

- 保持绿色浅深主题、系统字体与内容优先的层级；修改数值时查看官网 CSS 的实际角色。
- 保持真实下载清单驱动页面，明确显示验证、限制与签名状态；无产物时显示说明。
- 保持复制失败后的手动复制路径、搜索无结果说明、窄屏导航和焦点反馈。
- 不把本文件中的网页尺寸写入原生 SDK token，不用网页截图证明原生控件、系统兼容性或 SDK 消费者验收。
- 不将当前预览产物描述为所有操作系统均已稳定认证，也不把本地 Go 预览交付描述为已完成公网部署。
