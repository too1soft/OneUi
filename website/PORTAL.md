# OneUI 发布官网

本轮直接依据用户授权交付官网、完整文档和预编译 SDK，部署形态为 Linux x64 Go 程序及 Windows x64 预览程序。SDK 压缩包和 `releases.json` 放在可执行文件旁。公开网络域名、服务器部署及正式签名不属于本地交付的既成事实。

## 页面与交互

- 首页：说明 OneUI、展示版本入口和接入路径；绿色品牌，清晰的文档站排版。
- 下载：从服务端真实清单选择稳定/预览/实验渠道、版本、系统、架构和动态/静态链接；显示大小、SHA256、最低系统、工具链、签名与验收说明。无匹配产物时解释原因，无假下载按钮。
- 文档：现有 Markdown 转为完整路由和搜索索引；左侧分类、正文、页内目录；手机收起导航。接入文档优先说明预编译包，源码构建作为框架开发路径。
- 组件参考：迁移现有组件数据与接口表，并与最新公开头和文档交叉引用。
- Go CLI：校验发布文件；按固定版本下载到用户共享缓存并写入项目锁；离线验证；不在消费者环境编译 OneUI。

## 视觉方向

模式为 Read / Operate，扩展现有官网；保留绿色强调、系统中文字体、浅深主题。首页首屏直接给出 SDK 下载与接入文档，下载页优先呈现用户的目标平台及真实版本，不用营销统计替代内容。使用顶部主导航，文档使用目录侧栏；列表和分隔线组织密集信息。复制代码、过滤下载和搜索文档是主要交互。桌面与手机必须真实运行验证。

## 边界与模块

Nuxt 只参与构建，输出嵌入 Go，运行时无 Node 依赖。Go 标准库负责清单验证、只读下载、Range 请求、嵌入文件服务与缓存客户端。清单仅列公开文件，拒绝路径穿越、符号链接、缺失或被篡改文件。SDK 包从已有真实产物封装；原冻结输入保持不变。各包独立声明平台验证范围，不将 WSLg 或部分 Mac 原生证据写成全面稳定认证。

固定输出：`dist/oneui-website`；构建缓存：`out/portal-build`；当前报告：`out/native-release-review/portal-*`。本轮用户已批准延续 30 GiB 临时总上限，完成后清理本轮临时文件。
